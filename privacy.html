Privacy Policy

Legal

Last updated: April 18, 2026

This privacy policy describes how Negentropic Solutions LLC ("Negentropic Solutions," "we," "us") handles data accessed by the internal applications we build and operate on behalf of client organizations. It applies to every application listed in the Applications Covered section below. The list will be kept current as new applications are added.

These applications are internal tools for authorized users within their respective client organizations. They are not offered as public or consumer services.

Applications covered

PA Business Insights

An internal revenue analytics service. Accesses the following data via Google OAuth 2.0:

  • YouTube channel metadata (channel ID and title) — used to identify channels in internal reports.
  • YouTube Analytics reports — revenue and viewership metrics at monthly grain, used to produce internal per-channel analysis.

The application accesses data only from YouTube channels that the authorizing user owns or manages and explicitly grants access to during the Google OAuth consent flow.

How we use the data

Data accessed by each application is stored in a reporting database dedicated to the client organization on whose behalf that application operates. It is used solely to produce the internal reports, dashboards, and analyses that each application was built to produce. It is not sold, shared with third parties outside the client organization, or used for advertising, marketing, credit assessment, or any purpose unrelated to the stated function of the application.

Who can access the data

Access is restricted to Negentropic Solutions personnel operating the application on behalf of the client, and to authorized administrators within the client organization. Each application runs on infrastructure dedicated to its client — not on shared multi-tenant systems — and is not accessible to other clients or unrelated third parties.

Retention and deletion

Authorized users can revoke an application's access to their account at any time via the access-management settings of the relevant third-party service. For Google-based access, this is at myaccount.google.com/permissions. Upon revocation, the application stops accessing further data from the affected account. Any cached data already in the client organization's reporting database can be deleted on request by contacting the address listed below.

Security

OAuth credentials, refresh tokens, and other access secrets are stored on client-dedicated infrastructure with filesystem-level access restrictions (owner-only read permissions). Each application runs only on client-controlled infrastructure, not on shared multi-tenant systems. Access to that infrastructure is limited to the personnel identified above.

Google API Services User Data Policy

For applications listed above that access Google APIs, our use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Changes to this policy

If we update this policy, we will update the "Last updated" date at the top of this page. The list of Applications Covered will be kept current as new applications are added or existing applications are retired.

Contact

Questions about this policy or how data is handled: support@negentropic.llc.
